# ANNAELLE — макеты аналитики

Публичная демонстрация двух вариантов интерфейса для руководства. Вход в ChatGPT или GitHub для просмотра не нужен.

- `docs/current/` — текущий фирменный дизайн ANNAELLE.
- `docs/classic/` — прежний Teamify-вариант для сравнения.
- `docs/index.html` — выбор макета.

## Данные и безопасность

Все клиенты, суммы, события и метрики **синтетические**. Это не рабочая аналитика компании.
Два файла `app.js` идентичны: данные и правила расчётов совпадают, меняется только представление.
Нет API-вызовов Kommo/Altegio, ключей, серверных доступов, клиентских сообщений и истории приватных репозиториев.
Настройки анимации сохраняются только локально в браузере.

GitHub Pages публикует ветку `main`, папку `/docs`. Этот репозиторий не заменяет приватные проекты Sites или рабочий сервер.
Перед размещением реальных бизнес-данных потребуется отдельный защищённый сервер и авторизация.
